# Creto Content Studio — Creto Studio Demo

This folder contains an independent, static front-end concept for the Creto Studio demo programme. It is deliberately separate from the upstream platform source and does not replace upstream branding, licence files or notices.

## Preview locally
Open `index.html` in a modern browser. No build step is required for this static concept.

## Current scope
- Creto-branded presentation and sample content.
- Responsive layout and lightweight browser interactions.
- Fictional sample data only.
- No production backend, authentication, live order processing, or customer data connection.

## Next integration stage
Connect this front-end to the supported Creto Content Studio platform services, implement secure server-side operations, add environment-based configuration, and test the complete experience before public launch.
